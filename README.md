# 每日一字 - AstrBot 插件

## 📖 插件简介

每日一字是一个 AstrBot 定时推送插件,每天在指定时间(默认13:00)自动向QQ群发送一个随机汉字的详细学习内容。

## ✨ 功能特点

- 🕐 **定时推送**: 使用 APScheduler 实现专业的定时任务,每天固定时间自动推送
- 🤖 **AI驱动**: 调用 AstrBot 已配置的 AI 模型生成内容,无需额外配置 API Key
- 📚 **内容丰富**: 包含汉字的读音、含义、繁体、词源、造词和造句
- 🎯 **随机选择**: 每次选择非常见汉字,扩展词汇量
- ⚙️ **可配置**: 支持自定义推送时间和目标群号,使用 Cron 表达式精确控制
- 👤 **权限管理**: 支持配置管理员列表,管理员可手动触发推送
- 🔧 **丰富命令**: 提供手动推送、测试和状态查询功能
- 📊 **状态监控**: 可查看下次推送时间和调度器状态

## 📦 安装方法

### 方法1: 通过 AstrBot 插件市场安装(推荐)
1. 打开 AstrBot WebUI
2. 进入"插件管理"页面
3. 搜索"每日一字"
4. 点击"安装"按钮

### 方法2: 手动安装
```bash
cd AstrBot/data/plugins
git clone <插件仓库地址> astrbot_plugin_daily_word
```

## ⚙️ 配置说明

安装插件后,需要在 AstrBot WebUI 的插件管理页面进行配置:

| 配置项 | 说明 | 默认值 | 必填 |
|--------|------|--------|------|
| target_group_id | 目标QQ群号 | 空 | ✅ |
| push_time_hour | 推送时间-小时(0-23) | 13 | ❌ |
| push_time_minute | 推送时间-分钟(0-59) | 0 | ❌ |
| admin_qq_list | 管理员QQ号列表(数组) | [] | ❌ |

### 配置示例

```json
{
  "target_group_id": "123456789",
  "push_time_hour": 13,
  "push_time_minute": 0,
  "admin_qq_list": ["987654321", "111222333"]
}
```

**说明：**
- `admin_qq_list` 中的 QQ 号拥有使用 `/HANZI` 命令手动触发推送的权限
- 管理员可以在任意聊天窗口（私聊或群聊）使用命令
- 如果不配置管理员列表，则无法使用手动推送功能

## 🎯 使用方法

### 1. 自动推送
配置完成后,插件会在每天指定时间自动向目标群发送消息。

### 2. 管理员手动推送（新功能）
配置了管理员权限的用户可以随时手动触发推送：

**在任意聊天窗口中发送：**
```
/HANZI
```

**功能说明：**
- ✅ 只有在 `admin_qq_list` 中配置的 QQ 号才能使用
- ✅ 可以在私聊或群聊中使用该命令
- ✅ 立即生成并推送内容到目标群
- ✅ 会返回执行结果反馈

**权限示例：**
```
用户A (QQ: 987654321) → 在 admin_qq_list 中 → 可以使用 /HANZI
用户B (QQ: 555666777) → 不在列表中 → 无法使用，提示权限不足
```

### 3. 测试功能
管理员可以发送命令测试推送：
```
/每日一字测试
```
功能与 `/HANZI` 相同，但会提供更详细的测试反馈。

### 4. 查看状态
任何用户都可以查看插件状态：
```
/每日一字状态
```
可查看:
- 调度器运行状态
- 下次推送时间
- 目标群号
- 配置的推送时间
- 管理员列表

## 📋 推送内容示例

```
📚 每日一字已推送 📚

今日汉字: 耄

1. 读音: mào (第四声)

2. 含义: 年老,年纪很大。古代指七十岁到八十岁或九十岁的老人。

3. 繁体: 耄 (同简体)

4. 词源: 形声字,从老,毛声。本义指老年人头发斑白的样子。

5. 造词:
   - 耄耋之年
   - 老耄糊涂

6. 造句:
   爷爷虽已年届耄耋,但精神矍铄,思维敏捷。
```

## 🎮 命令列表

| 命令 | 权限要求 | 功能说明 |
|------|---------|---------|
| `/HANZI` | 管理员 | 立即生成并推送每日一字内容 |
| `/每日一字测试` | 管理员 | 测试推送功能 |
| `/每日一字状态` | 所有人 | 查看插件运行状态和配置信息 |

## ⚠️ 注意事项

1. **LLM 配置**: 使用前请确保 AstrBot 已正确配置 LLM 提供商(如 OpenAI、DeepSeek、Gemini 等)
2. **QQ平台**: 插件目前仅支持 QQ 平台推送
3. **群号格式**: 群号请填写纯数字,不要添加其他字符
4. **权限要求**: 确保机器人在目标群中有发送消息的权限
5. **时区**: 推送时间基于服务器本地时间

## 🔍 故障排查

### 未收到推送
1. 检查插件是否已启用
2. 检查目标群号是否正确
3. 检查机器人是否在群中
4. 查看 AstrBot 日志是否有错误信息

### AI 生成失败
1. 检查 LLM 提供商配置是否正确
2. 检查 API Key 是否有效
3. 检查网络连接是否正常
4. 查看错误日志中的具体错误信息
